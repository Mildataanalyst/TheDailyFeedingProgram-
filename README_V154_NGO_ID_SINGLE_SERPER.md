# DFP 2.0 Frontend v154

This release adds a separate **Karnataka Recovery** control centre and makes the permanent DFP NGO ID visible across the application.

## Karnataka Recovery buttons

1. Technical test run — `TEST_05_all_partner_recommendations_44.csv`
2. Verify known URLs / saved candidates — `RUN_01_zero_query_known_urls_6091.csv`
3. Run the missing query only — `RUN_02_missing_query_only_10138.csv`
4. Enhanced historical recovery — `RUN_03A...10102.csv`, then `RUN_03B...10102.csv`
5. New / unlinked records — `RUN_04_new_unlinked_2035.csv`
6. Same-name identity collisions — `RUN_05_identity_collisions_search_376.csv`
7. Optional Firecrawl retry — use the retry CSV generated by a completed run

The panel includes single-account Serper preflight, row and provider concurrency, a 59,000-credit run ceiling, pause/resume/end controls, saved runs and downloadable audit/retry outputs.

## NGO IDs in the interface

`DFP-NGO-XXXXXXXXXXXXXXXX` is displayed in:

- Lead Pool;
- PM workstream/shortlisting;
- Combined and Final Ranking;
- Contact Tracker;
- repository and recovery previews.

The DFP NGO ID Registry card can inspect the historical inventory, force a backfill with the core backend admin password and export the ID registry.
